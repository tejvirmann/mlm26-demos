# MLM26 Demos

Demo material and Claude Code skills used in MLM26 sessions.

## Contents

- [`caveman/`](caveman/) — Claude Code skill that switches responses into an
  ultra-compressed "caveman" communication style to cut output tokens while
  keeping technical accuracy. Supports multiple intensity levels (`lite`,
  `full`, `ultra`) plus classical-Chinese (wenyan) variants.

## Usage

Drop a skill folder into your Claude Code skills directory (or reference it
directly) to make it available as a slash command, e.g. `/caveman`.
